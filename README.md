# Приглашение для Яны

Небольшой интерактивный сайт-приглашение на свидание. Внутри — цветочный дизайн,
плавные переходы, шуточная кнопка «Нет», подтверждение согласия, авторский
календарь и отправка выбранных даты и времени в Telegram.

## Возможности

- адаптивный интерфейс для телефона и компьютера;
- пионы, розы и гортензии, собранные средствами CSS;
- четыре последовательных экрана приглашения;
- календарь с блокировкой прошедших дат;
- готовые варианты времени и выбор произвольного времени;
- серверная отправка результата через Telegram Bot API;
- токен Telegram никогда не передаётся в браузер.

## Локальный запуск

Требуется Node.js версии `22.13.0` или новее.

```bash
npm install
npm run dev
```

После запуска сайт будет доступен по адресу `http://localhost:3000`.

## Настройка Telegram

Создайте локальный файл `.env.local` по примеру `.env.example`:

```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
TELEGRAM_CHAT_ID=id_чата_получателя
```

`.env.local` исключён из Git и не должен попадать в репозиторий. Перед получением
`TELEGRAM_CHAT_ID` отправьте боту команду `/start`.

## Проверка

```bash
npm run build
npm test
```

Основной интерфейс находится в `app/page.tsx`, стили — в `app/globals.css`, а
серверная отправка в Telegram — в `app/api/send-date/route.ts`.
